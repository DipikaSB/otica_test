# Magento 2 - Guest To Customer
Entering the wrong email address during purchase is a very common mistake, especially on order by phone transactions. Reduce the number of hours and frustration each time a customer mistype their email. With our extension the is no need to cancel and reorder just to correct a simple email in an email address.

# Magento Assign Guest Order to Customer
In case there is a guest order placed on the existing user’s email then while converting guest to customer new account won’t be created, but this order will be signed to the existing customer with the automatic adding of shipping and billing addresses to a customer address book. This way Magento Convert Guest to Customer plugin saves you from having any duplicated accounts.

Magento 2 Convert Guest to Customer module assigns guest order to customer by email automatically, but in case buyer set different emails placing orders as guest and then as a customer, you still can manually define a proper customer for the order or even change order customer (assign a new customer to the order). 

# Creation of New Customer Account
While converting a guest order with an unregistered email to the customer a new account is created. The newly created customer is attached to the store view guest order was assigned to. After the guest order is converted to the customer it becomes attached to the account and the shipping and billing addresses are automatically added and marked as default for a customer.

# Automatically Convert Guest To Customer
Our Magento Guest to Customer converter has an option to assign all Magento guest orders to customer accounts. Once the guest places an order customer account will be created and Magento assign guest to customer plugin will convert the order to the customer automatically.
Converting Old Guest Orders
In case you have installed this extension and have a huge amount of old guest orders you would like to migrate to customers use a feature provided by our Magento 2 convert guest to customer module and assign guest orders at once by pressing the“ Convert all Old Guests to Customers” button in store configurations.

# New Account Email and Password
Once a new account is created during the conversion process, a customer password is generated randomly and email notification about the account creation is sent to the customer.  The password is not included in the email for security reasons, but the email contains the link to the password reset page where the customer can change it.

# Change Customer
While assigning guest order to customer Magento 2 Convert Guest to Customer extension creates new customer on the basis of guest order information. However, this module allows you to change the customer assigned to the particular order if needed.

 
## Features
- Edit order email address.
- Update order customer email address (optional).
- Add order email change history to order comment along with the admin user who changes the email address.
- convert guest to customer on admin order grid, edit order on backend
- Allow customer import there guest orders to your his account (require email address and order id)

## ✓ Install via composer (recommend)
Run the following command in Magento 2 root folder:

```
composer require ecomteck/module-guest-to-customer
php bin/magento module:enable Ecomteck_GuestToCustomer
php bin/magento setup:upgrade
php bin/magento setup:static-content:deploy -f
php bin/magento cache:clean
```
